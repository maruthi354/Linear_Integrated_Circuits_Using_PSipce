This repository contains my hands-on work on analog circuit design using operational amplifiers (Op-Amps). All circuits are designed and simulated using PSpice, with a focus on understanding circuit behavior through output waveforms.

The aim of this project is to build a strong foundation in analog electronics by implementing commonly used Op-Amp circuits and verifying their performance through simulation.

Tool used: PSpice

Each circuit includes schematic design and output waveform
Simulation is used to verify theoretical results

Reference

This work is based on concepts from the book:
Op-Amp and Linear Integrated Circuits
